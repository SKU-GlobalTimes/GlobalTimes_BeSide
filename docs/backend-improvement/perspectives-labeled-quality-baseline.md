# Perspectives 정답 표본 품질 기준선

## 목적

이 기준선은 실제 데이터가 저장된 로컬 DB의 작은 정답 표본을 이용해 현재 latest-first MySQL FULLTEXT 후보 조회 품질을 평가한다.

`perspectives-multilingual-fulltext-integration.md`의 통제된 통합 테스트는 백엔드 처리 흐름이 의도대로 동작하는지를 검증한다. 이 문서는 한 단계 더 나아가 현재 쿼리가 실제 수집 데이터에서 어떤 기사를 반환하는지 기록한다.

## 측정 환경

| 항목 | 값 |
| --- | --- |
| 측정일 | 2026-07-24 |
| DB | 데이터가 저장된 로컬 MySQL 8 |
| 전체 기사 | 9,814건 |
| 고유 URL | 9,814개 |
| 발행일 범위 | 2015-06-07 ~ 2026-06-22 |

| 실제 외부 번역 호출 | 2회 |

동일한 조회는 `sql/perspectives-labeled-quality-sample.sql`로 재현할 수 있다.

따라서 선정 단위는 “전체 데이터의 축소판”이 아니라 “기존 검색 흐름에서 서로 다른 성공·실패 원인을 재현하는 고정 진단 사례”다. 기준 기사를 정한 뒤에는 현재 `KeywordExtractor`의 검색어를 사용하고, 기준 기사 자신을 제외한 전체 article 테이블에서 MySQL FULLTEXT latest-first 상위 5건을 기계적으로 조회했다. 라벨링 대상은 임의로 다시 고른 기사가 아니라 그 쿼리가 반환한 후보와 빈 슬롯이다.

## 라벨 판정 기준

| 라벨 | 판정 기준 |
| --- | --- |
| `same_event` | 중심 인물·기관, 구체적인 사건 또는 행동, 시간 맥락이 모두 같은 기사 |
| `related_topic` | 주제나 주요 인물은 같지만 서로 다른 사건을 다루는 기사 |
| `unrelated` | 넓은 단어나 인물 일부만 겹치며 기준 사건을 다루지 않는 기사 |
| `uncertain` | 저장된 제목과 설명만으로 안정적으로 판정할 수 없는 기사 |

판정 근거로 저장된 제목, 설명, 출처·국가·언어, 발행 시각을 사용했다. 기사 전문을 임의로 추정하거나 전체 데이터에 같은 라벨 품질이 적용된다고 가정하지 않았다.

## 지표 계산 기준

`Precision@5`는 결과가 5건보다 적더라도 분모를 5로 고정한다.

```text
상위 5개 슬롯에 포함된 same_event 기사 수 / 5
```

조회 결과가 5건보다 적으면 빈 슬롯은 관련 없는 결과로 계산한다. `Useful Precision@5`는 `same_event`와 `related_topic`을 함께 유용한 결과로 계산한다. `Hit@5`는 상위 5개 안에 `same_event`가 하나라도 있으면 1이다. 최종 API가 국가별로 후보를 묶기 때문에 반환 국가 수도 별도로 기록한다.

> **해석 주의:** `Precision@5=0.267`은 전체 9,814건에서 무작위 추출해 계산한 서비스 정확도가 아니다. 기존 작업에서 의도적으로 성공·노이즈·topic-only·결과 없음·다국어 유형을 포함한 6개 고정 진단 표본의 매크로 값이다. 따라서 “Perspectives의 전체 정확도는 26.7%다” 또는 “기사 9,814건 중 26.7%가 정확하다”고 표현하면 안 된다.

이 값은 동일한 6개 기준 기사와 같은 라벨 규칙을 유지한 채 keyword, query, ranking 또는 데이터 coverage가 바뀌었을 때 개선 전후를 비교하는 회귀 기준선으로만 사용한다. 제품 전체 품질을 추정하려면 국가·언어·카테고리·발행 시기를 층화한 별도 무작위 표본과 독립적인 정답 라벨 검토가 필요하다.

또한 이 지표는 `ArticleRepository.findPerspectives`가 찾은 후보 중 latest-first 상위 5개 슬롯을 평가한다. 국가별 최대 3건으로 묶이는 최종 Perspectives API 응답 전체의 precision을 측정한 값은 아니다.

## 해석

- `8146`은 추출한 핵심 인물과 사건이 현재 진행 중인 동일 사건을 찾을 수 있음을 보여준다.
- `8147`은 첫 번째 동일 사건 결과가 있어도 이후 순위에 잘못된 맥락의 기사가 섞일 수 있음을 보여준다.
- `8149`는 넓은 주제 일치로 Useful Precision은 높지만 동일 사건 Precision은 0일 수 있음을 보여준다.
- `8148`과 `8468`은 실행한 검색에서 candidate가 0건이므로 ranking을 평가할 수 없다. 독립적인 row 존재 확인 없이 source coverage와 retrieval failure 중 하나로 확정하지 않는다.
- `9440`은 번역 전에도 라틴 문자 인물명이 공통인 다국어 저장 기사를 찾을 수 있음을 보여준다.

이 표본만으로 번역문 저장, Elasticsearch, Vector DB, embedding, clustering 또는 ranking 변경을 도입하지 않는다. 향후 ranking 실험은 `8147`처럼 관련 기사와 무관한 기사가 함께 존재하는 표본을 사용해야 한다. candidate가 없는 표본을 근거로 ranking이나 source coverage 중 한쪽이 문제라고 확정해서는 안 된다.
